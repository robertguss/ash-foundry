# ash_foundry_new

The thin Mix archive for creating a new AshFoundry application.

```bash
mix archive.install hex phx_new 1.8.13
mix archive.install hex igniter_new 0.5.34
mix archive.install hex ash_foundry_new 0.1.0
mix ash_foundry.new my_app
```

Every wizard selection has a CLI flag. Run `mix help ash_foundry.new` for the
deterministic form.
